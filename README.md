# cfd-calculator

Single-file CFD calculator (React via CDN) for estimating:
- maximum lot size from margin, leverage, and risk settings
- stop-out constrained loss limits
- margin and loss metrics for the selected lot size

## GitHub Pages

1. Commit `index.html` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch** and choose your branch with `/ (root)`.
4. Open the generated Pages URL.
